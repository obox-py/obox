# i18n.json

```json
[
  {"id": "title", "lang": "zh-CN", "value": "示范扩展"},
  {"id": "title", "lang": "en-US", "value": "Demo extension"}
]
```

- id 规则：小写字母开头，段内小写字母+数字，可用点分节（`title`、`dialog.ok`）
- 每条 id 必须含 `zh-CN`，否则整份文件拒绝加载
- oml 里用双花括号包住 `i18n.<id>` 引用，渲染前替换；缺当前语言时按「语言基码 → 基码缺省（zh-* 用 zh-CN、en-* 用 en-US）→ zh-CN」回退，未注册的原样保留；注册必须含 zh-CN
- 宿主在扩展激活时读取 i18n.json；打包会把它一起放进 .oix

## 语言覆盖

- 设置里可选的语言固定四种：zh-CN、zh-HK、zh-TW、en-US（宿主 `obox.i18n.SUPPORTED_LANGUAGES`）
- 每条 id 必须四种语言齐全，缺任何一种视为文案不完整；新增语言要先整套文案齐备再进设置
- zh-HK 与 zh-TW 用繁體中文，术语与 obox 保持一致（扩展=擴充功能、设置=設定、界面=介面、网络=網路、默认=預設）

## Python 侧文案

扩展在 Python 里产出的文案（视图数据、`register_view` 的标题、`showMessageBox` 的字段、`contributes.app.title`）同样可以写双花括号包住的 `i18n.<id>` 占位符，宿主在渲染时按该扩展的命名空间替换：

```python
context.register_view("demo.main", "views/main.oml", "main", "{{i18n.title}}")
context.send(view_data_message(context.extension_id, view_id, {"status": "{{i18n.status.ready}}"}))
```

未注册的占位符原样保留，与 oml 里的回退规则一致；扩展不需要自己维护翻译表。

## 打包约束

- .oix 只包含入口 import 图可达的模块（各自编译为 pyd）与 extension.json、i18n.json、assets/、views/
- 扩展的运行期依赖必须落在 import 图内：兄弟模块用 `import` 引用，不要用 `exec(open(...).read())` 或读目录里的 .py，否则装完会因缺文件激活失败
