# i18n.json

```json
[
  {"id": "title", "lang": "zh-CN", "value": "示范扩展"},
  {"id": "title", "lang": "en-US", "value": "Demo extension"}
]
```

- id 规则：小写字母开头，段内小写字母+数字，可用点分节（`title`、`dialog.ok`）
- 每条 id 必须含 `zh-CN`，否则整份文件拒绝加载
- oml 里用双花括号包住 `i18n.<id>` 引用，渲染前替换；缺当前语言时按「语言基码 → 基码缺省（zh-* 用 zh-CN、en-* 用 en-US）→ zh-CN」回退，未注册的原样保留；注册必须含 zh-CN
- 宿主在扩展激活时读取 i18n.json；打包会把它一起放进 .oix
