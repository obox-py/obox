把想法盘问到没有隐含假设为止。除 ADR 之外不写任何文件、不改代码、不代表任何后续动作已被授权。

## 设计树

要盘的不是一张问题清单，是一棵**设计树**：每个决策下面挂着依赖它的决策。

```
目标
├── 范围
│   ├── 首版做什么        <- 依赖上面"范围"
│   └── 明确不做什么
└── 方案
    ├── 选型              <- 依赖"首版做什么"
    └── 失败处理
```

判断一个决策挂在谁下面，问自己："这个问题的答案会不会因为另一个答案而改变？"会，就是它的下游。

## 按轮推进

**前沿**是当前所有前置条件已经定了的决策——不用猜任何未听到的答案就能问的那些。

一轮把整个前沿问完，等用户答完，把结论并进树里，前沿自然向外推进，再问下一轮。

依赖本轮尚未定夺的问题，属于下一轮，不属于本轮。一轮只问一个问题、或把有依赖关系的两个问题塞进同一轮，都是错的。

## 每轮给推荐

每个问题都给出你的推荐答案和一句理由；推荐项放在选项的第一个并标 `(Recommended)`。用户否决时，追问一句反面理由，不要默默换答案。

## 事实与决策

- **事实是你的活**：文件、配置、命令输出能回答的，自己查，绝不摆到问题里让用户重述。
- **决策是用户的**：每个决策都要用户点头；用户说"随便/你定"时，把你的推荐记为**假设**并明说出来，不要当成已定。
- 查不动的事实（需要用户偏好、授权、外部信息）才进前沿。

## 提问格式

一切提问只用 AskUserQuestion，形态固定：

```js
AskUserQuestion({
  "questions": [
    {
      "header": "",
      "question": "",
      "options": [
        {"label": "", "description": ""}
      ],
      "multiSelect": false
    }
  ]
})
```

填法：一轮一次调用；多个问题就是 `questions` 里多项；`header` 写问题主题，`question` 写问题正文并带上推荐理由；`options` 里第一项是推荐方案、`label` 结尾标 `(Recommended)`；单选一律 `multiSelect: false`。工具末尾自带的输入项就是自定义入口，不要另写"自定义"选项；格式要求写进 `header` 或 `question`。单轮多个问题间不能有因果关系，否则需要拆分多轮提问。

## 记录 ADR

共识达成后，如果结论**三条全真**，就提议记一份 ADR——提议也走 AskUserQuestion，用户同意才写：

1. **以后很难推翻**：改回去的代价明显
2. **没有上下文会显得奇怪**：后来的人看代码会问"当初为什么这么干"
3. **是真实取舍的结果**：确实存在其他方案，你按具体理由选了这一个

容易推翻的、不意外的、没有替代方案可言的，一律不记——"我们做了显而易见的事"不值得占一个编号。

- **位置**：`{df_proj_dir}/docs/adr/`。`df_proj_dir` 由用户指定；没指定就用当前工作目录。本 skill 不从任何别处取路径。
- **目录惰性创建**：第一条 ADR 要写时再建 `docs/adr/`，平时不建空目录。
- **命名**：`NNNN-slug.md`，四位序号；扫该目录已有文件取最大序号 +1，首条 `0001`；`slug` 用英文短横线短语，不写中文。
- **格式**：严格按 `templates/adr.md`——默认形态就是极简（标题 + 1-3 句：上下文、决定、为什么）。只有确实有价值时才加可选的 Status / Considered Options / Consequences，不要为填满而填。
- **写完回报**：给出文件路径与序号，并把这条决策在共识清单里标成"已记 ADR"。

## 停止条件

前沿为空——每条分支都走到、没有默认假设被悄悄留下——**并且**用户明确确认共识达成。二者缺一不可；用户没确认就继续盘问，或明说还差哪几条。

确认之后还有一步：按上面的条件判断要不要记 ADR，要就提议、写完才算结束。

## 边界

- **只写 ADR**：除了 `{df_proj_dir}/docs/adr/*.md`，不产出任何文件——规格、设计、任务、状态文件都不写。
- **不改代码**。
- **不替用户决定**：记不记 ADR 也是用户的决定。
- **不查用户能查的**。
- **不提前问**：前置未定的留到下一轮，宁可少问也不猜着问。
- **宿主没有 AskUserQuestion 时**：退回编号列表提问，不跳过提问。
