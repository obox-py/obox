# obox UI 规范

参考基准：`tmp/1.png`（深色设置页）。从图中量得：窗口底色 #292a2b、输入框底色 #3c3c3c、输入框高 27px、正文约 13px、页面标题约 26px、导航行距约 25px。

本文定义 obox 全部界面的字号、字重、行高与间距标准。主题只负责取值（`styles.qss` + `PALETTE`），组件按本规范实现。

## 1. 字体与基准

- 字体族：HarmonyOS Sans SC；回退 Noto Sans SC → Microsoft YaHei UI → Segoe UI
- 正文基准：14px；密集列表与设置项：13px；说明文字：12px
- 行高：正文 1.57（14/22）、密集列表 1.54（13/20）、说明 1.5（12/18）、标题 1.3–1.4
- 字重：400 正文、500 强调项与按钮、600 标题与数值

## 2. 字号规范

| Token | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| `display` | 26 / 34 | 600 | 页面主标题（设置页「常用设置」这类） |
| `title` | 20 / 28 | 600 | 区块标题、浮层标题 |
| `subtitle` | 16 / 24 | 600 | 卡片标题、分组标题 |
| `body` | 14 / 22 | 400 | 通用正文、按钮文字 |
| `body-medium` | 14 / 22 | 500 | 设置项名称、列表主字段 |
| `dense` | 13 / 20 | 400 | 密集列表、导航项、表格单元格 |
| `dense-medium` | 13 / 20 | 500 | 设置项标题、表头 |
| `caption` | 12 / 18 | 400 | 说明与辅助文字、状态 |
| `micro` | 11 / 16 | 500 | 标签、徽标、图表刻度 |

字号只允许取上表的值；新增字号必须先改本表。

## 3. 间距规范

标尺：`2 / 4 / 8 / 12 / 16 / 20 / 24 / 32`，禁止 5、6、10、14、18 这类取值。

| 场景 | 取值 |
|---|---|
| 图标与文字 | 8 |
| 同一控件组内元素（标题与说明） | 4 |
| 标签与输入框 | 8 |
| 设置项之间 | 24 |
| 卡片内部 padding | 16（上下 14） |
| 卡片之间 | 16 |
| 区块之间 | 32 |
| 页面四周留白 | 24 |
| 浮层面板 padding | 22 / 18 / 22 / 16 |
| 浮层按钮间距 | 8 |

行间距不用魔法数字：标题与正文之间 4，正文多行靠行高，段落之间 8。

## 5. 各模块标准

### 标题栏
- 高 40；标题 13/600；图标 18；窗口按钮 40×30，线条 1px
- 与内容区之间不画分隔线，靠底色差 1 级

### 侧栏与导航
- 侧栏宽 56，图标 22，选中用主色；导航项高 40，文字 14，选中左侧 2px 主色条
- 导航项之间不设间距，靠高度与内边距区分

### 内容区
- 页面四周 24；页面标题 `display`（可在密集页降为 `title`）
- 区块之间 32；区块内标题与内容 8

### 设置页
- 分类导航宽 180，项高 40，文字 14；选中主色 + 浅底
- 分类标题 `title`；设置项标题 `dense-medium`（13/500），说明 `caption`（12/400），标题与说明间距 4，说明与控件间距 8
- 设置项之间 24；控件宽以内容为准，短控件不拉满

### 表单
- 标签在上，控件在下，间距 8；必填标记用主色星号，与标签间距 4
- 错误文字 `caption` 用危险色，与控件间距 4
- 同一行多控件间距 12

### 卡片与列表
- 卡片 padding 16/14，标题 `subtitle` 或 `dense-medium`，描述 `caption`
- 列表行高 44（可点）或 36（只读），行内主次字段间距 4
- 卡片列表每行一个卡片时，行间距 8

### 表格
- 行高 36，表头 36；单元格左右 12，文字 13
- 数字列右对齐，文本列左对齐；表头用 500 字重

### 浮层与对话框
- 宽 420，标题 `title`，正文 `body`，按钮高 32、间距 8、右对齐
- 遮罩 30% 黑；不叠阴影，靠 1px 描边分层

### 提示与提醒
- 提示条：文字 14，图标 16，上下 12 左右 16；顶部距标题栏 20
- 轻提示（toast）：标题 14/600，正文 12，宽 ≤ 360，4 秒自动消失

### 托盘菜单
- 宽 240，行高 44，文字 13，圆角 10，分隔线 1px，悬停用强调淡底

### 图表
- 标题 14/500；刻度 11；图例 12；网格线 1px、用分隔线色
- 图表区域四周留白 8，不与卡片描边贴合

### 扩展页面
- 扩展视图沿用以上全部标准；扩展自定义样式只能改颜色与描边，不得改字号与行高
- 扩展若需要新字号，先在本文件登记

## 6. 颜色与对比度

- 正文对比度 ≥ 4.5:1，辅助文字 ≥ 3:1，图标 ≥ 3:1
- 层级顺序：页面底 < 卡片面 < 浮层面；分隔线只用于 1px 边界
- 主色只用于可操作元素与选中态；危险色只用于破坏性操作
- 浅色与深色主题共用同一套字号、间距与尺寸，只换颜色

## 7. 落地与代码约定

- 主题：`theme/<kit>/styles.qss` 负责样式，`PALETTE` 提供颜色与尺寸常量；组件在 `obox/ui/components`
- Qt 的 QSS **不支持 line-height**：行高通过「字号 + QLabel 上下 padding」或布局 spacing 实现，取值见第 3 节；不要用 `line-height` 属性
- QSS 变量写法：键名用双花括号包裹，加载时替换为 PALETTE 取值
- 组件尺寸常量放 `PALETTE`（CONTROL_HEIGHT、RADIUS_CONTROL、RADIUS_CARD），不要散落在组件里
- 新增或修改字号/间距/尺寸，必须同一次提交更新本文件与对应组件
