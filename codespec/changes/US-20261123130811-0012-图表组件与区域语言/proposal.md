# 组件归位与区域语言 · 组件迁入 obox、主题只做样式

## 背景

三件事合并成一次重构：把 21 个 UI 组件从两套主题包迁进 obox，只保留一份实现，主题退化为「QSS + 调色板 + 字体」的样式包；新增 matplotlib 图表组件（非网页、可交互、多进程可用）；语言体系从两档升级为按 BCP-47 地区配置并带缺省回退。

## 目标

- 21 个组件 + 新增 chart 只在 obox 里实现一份，主题不再提供组件类
- 主题提供 QSS、调色板（颜色/圆角/控件高度）、字体、图标色与间距；组件绘制从调色板取色
- chart 用 matplotlib 的 QtAgg 画布嵌入，数据经消息跨进程下发，支持缩放、平移、悬停坐标与重置
- i18n 支持区域：zh-HK、zh-TW 未单独配置回退 zh-CN，en-GB 等回退 en-US，其它回退 zh-CN
- 设置的语言项列出 Qt 可枚举的全部地区，用原生地区名显示并支持搜索
- obox 与所有扩展必须提供 zh-CN 缺省，缺省时回退并记日志

## 范围

**做：**

- 把 theme/{light,dark}/components 的 21 个组件迁到 obox/ui/components，合并为单份实现
- 引入调色板契约：主题 provider 暴露 palette（颜色、圆角、控件高度、字体），组件经参数或上下文读取
- 主题包瘦身：只保留 theme.json、QSS、palette、fonts、图标色与间距
- 新增 chart 组件与图表数据协议、交互手势与重置
- i18n 区域回退链、强制 zh-CN 校验
- 设置语言项改为全量地区列表（原生名 + 搜索 + 持久化）
- 主题工具、组件契约、技能文档与测试同步

**不做：**

- 不做网页渲染
- 不做 3D 图表、动画播放、子图导航、保存图片工具栏
- 不引入 babel 等额外 locale 数据包
- 不改扩展清单格式；组件标签数量仍按「21 + 宿主 chart」计算

## 需求草案

1. 21 个组件与 chart 全部由 obox 提供，主题不再实现组件类
2. 主题 provider 暴露调色板与 QSS；组件自绘颜色、圆角、控件高度从调色板取
3. 装配器按 obox 组件表实例化，不再从 provider.component_types 取；provider 校验改为只校验样式能力
4. 两套主题的差异只体现在 QSS 与调色板取值
5. chart 接受 JSON 数据（类型、series、x 标签、标题），在 QtAgg 画布渲染
6. 图表交互：滚轮缩放、拖动平移、悬停显示坐标、右上角重置
7. 扩展在宿主进程发数据，obox 在 UI 进程渲染，跨进程不传 matplotlib 对象
8. 语言解析：精确匹配 → 语言基码回退 → zh-CN；i18n 注册必须含 zh-CN，否则拒绝并记录
9. 设置的语言项列出 Qt 可枚举的全部地区，原生地区名显示（zh-CN → 中国大陆、en-US → America），带搜索
10. 语言选择写进配置，重启后生效，切换时重建视图

## 关键取舍

- 组件单份实现换来一致性：两套主题不再各维护一份组件，修一次两套都生效；代价是主题从「组件包」降级为「样式包」，契约与打包都要改
- 调色板由主题注入：组件仍在 obox，不能 import 主题包，只能从 provider 拿色值
- matplotlib 进运行时依赖（约 50MB）：换取成熟绘图与缩放交互，不自己写绘图
- QtAgg 嵌入画布：非网页、进程内渲染；图表数据只传 JSON，不传对象
- 语言列表用 Qt 的 QLocale 枚举：不引入 babel，显示名为原生地区名
- 回退按语言基码：中文地区保持中文、英文地区保持英文，其它落 zh-CN

## 与基线的冲突

- 基线「界面套件清单与加载」「组件契约不变」规定 21 个标签由套件提供，本次改为 obox 提供，需 MODIFIED
- 基线「组件能力接口与消息处理分界」描述的是套件组件，宿主组件要走同一套状态/事件映射，需补
- 基线「视觉统一」「主题色板与文字层级」需补调色板契约（组件绘制从调色板取值）
- 基线「i18n 注册与占位替换」只写 zh-CN 回退，需 MODIFIED 加区域回退与强制 zh-CN
- 基线「设置扩展」语言项写死两档，需 MODIFIED 为全量地区
- 基线「扩展开发技能」「主题开发技能」的标签计数、组件归属与语言示例要同步

## 假设

- 主题 = QSS + palette + fonts + 图标色 + 间距，不再含组件类
- chart 用 matplotlib 的 QtAgg 画布，交互为缩放/平移/悬停/重置
- 语言列表取 Qt 可枚举的全部地区，原生名显示
- 回退按语言基码
