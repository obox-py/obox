# 设置自启动与多语言适配 Proposal

## 背景

设置页「行为」分类目前只有关闭行为一项（obox/app.py:841-856），没有开机自启动。托盘菜单与关闭询问对话框的文案是硬编码中文（obox/ui/tray.py:26-36、obox/ui/close_dialog.py:12-24），切到英文后仍是中文。

语言下拉用 QLocale 全量 locale 枚举（obox/app.py:786-827，上百种），而 obox/i18n.json 与 8 个扩展的 i18n.json 只有 zh-CN 与 en-US 两条文案，选其它语言整屏回退中文；配置里存的还是标签而非语言码（.obox/config.json 的 language 为「中国大陆」），与 spec.md:898 要求的 en-US 不符。

浅色套件的正文被用户描述为灰色（theme/light/theme.py:8-9，TEXT=#1d2129、TEXT_MUTED=#86909c）。扩展 rdp.chenzhi 安装到 %LOCALAPPDATA%\\obox\\extensions\\rdp.chenzhi 后显示未激活，扩展管理统一显示「失败」，界面看不到原因。

## 目标

- 设置 → 行为 出现「开机自启动」开关，改动即时生效并持久化。
- 关闭询问对话框、托盘菜单、窗口提示与扩展管理页的文案全部走 i18n。
- 设置里列出的每种语言，obox 与全部扩展都有对应文案。
- 浅色套件的主文本为纯黑，层级仍靠次级灰阶区分。
- rdp.chenzhi 安装后可正常激活；任何扩展失败都能在界面上看到原因。

## 范围

**做：**

- 新增 `obox.autostart` 设置项与开关，挂在 behavior 分组。
- 托盘、关闭对话框、toast、扩展管理的硬编码中文抽成 i18n 条目。
- 语言清单收敛为有完整文案的语言集合，补齐 obox 与 extensions/* 的 i18n.json。
- 语言设置统一存 BCP-47 码，旧配置里的标签在启动时迁移。
- theme/light 的 TEXT 改为 #000000，同步 QSS 与组件取色。
- 修掉 rdp.chenzhi 未激活的根因（fields.py 未随 .oix 打包），管理页展示失败原因。

**不做：**

- 不新增语言（清单外的语言不入设置）。
- 不重做主题配色与圆角间距，只改文字色。
- 不做扩展市场、自动更新与失败重试策略。

## 需求草案

1. 设置 → 行为 增加「开机自启动」开关，开写 HKCU Run 并指向当前可执行文件，关则删除；源码运行（非打包）时开关禁用并说明仅安装版可用。
2. 关闭询问对话框、托盘菜单、toast、扩展管理页、错误通知的文案来自 i18n.json，切语言后立即生效。
3. 设置的语言下拉只列 obox 与扩展文案齐全的语言，本次为 zh-CN、zh-HK、zh-TW、en-US；切换后全界面与已装扩展文案同时切换。
4. 浅色套件正文、标题、设置项标题、列表与输入文本为纯黑，说明与禁用态保留灰阶。
5. rdp.chenzhi 的 .oix 包含运行期依赖文件；任何扩展激活失败时，扩展管理页与通知都显示失败原因。

## 关键取舍

- **语言清单收敛到 4 种**，否掉「保留上百种 locale 再逐个补齐」：文案量与语言数线性增长，且未翻译语言只会回退中文，体验更差。新增语言的门槛是整套文案齐全。
- **语言值存 BCP-47 码**，否掉继续存标签：标签随 Qt 本地化改名而漂移，且与 spec.md:898 的场景冲突。旧配置按标签表迁移一次。
- **主文本纯黑、次级保留灰阶**：全黑会丢掉说明与禁用态的层级。
- **自启动只写 HKCU Run**，不用启动目录快捷方式：不需要额外文件，卸载时由安装器清理。源码运行不写，避免把 python.exe 写进自启动。
- **rdp 修复落在打包清单**，否掉把 fields.py 内联进 extension.py：字段表还要给其它模块读，内联会让 pyd 与源码两套事实。

## 与基线的冲突

- spec.md:522-534「主题色板与文字层级」的场景写明「正文是中深灰」「大面积背景不出现纯黑与纯白」，本次把正文改成纯黑，需要在 delta-spec 里替换该场景。
- spec.md:786 的语言下拉来自全量 locale 枚举，本次收敛为固定集合，属于能力边界变化。
- spec.md:828「关闭行为设置」只列关闭行为，本次新增自启动，需要在该需求内追加。
- spec.md:908「扩展故障隔离」已要求「界面提示失败原因」，实现只提示扩展名，属于实现缺口而非新需求。

## 假设

- 用户未在盘问卡上作答，按推荐选项推进：语言清单收敛到 4 种；主文本纯黑、次级保留灰阶。
- 自启动在源码运行时不生效，只对安装版可用。
- 发布节奏：本次改动合并并打包冒烟后推送分支；v1.0.1 tag 与 Release 等验收通过后再发。
