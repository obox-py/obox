# 托盘与单实例 Proposal

## 背景

obox 目前关闭窗口即退出，没有托盘，也没有实例互斥；需要常驻托盘并与设置联动。

## 目标

同一用户只允许一个 obox 进程；关闭窗口时可在「最小化到托盘」与「退出」之间选择，并可记住选择；托盘常驻右下角，可恢复窗口或退出。

## 范围

**做**：命名管道单实例与唤醒、QSystemTrayIcon 与菜单、关闭询问与记住选择、设置新增「行为」分类与关闭行为项、配置持久化。

**不做**：多用户会话隔离（每个 Windows 用户各自一份实例即可）、开机自启、托盘气泡通知、macOS/Linux 托盘差异。

## 需求草案

- 启动时用命名管道（按用户区分）探测已有实例：有则发送「显示」请求后退出，无则成为主实例
- 托盘图标常驻，左键双击恢复窗口，右键菜单：显示主窗口、设置、退出
- 关闭窗口时按配置处理：每次询问（三选：最小化到托盘 / 退出 / 取消，带「记住我的选择」）、直接最小化、直接退出
- 记住选择写入配置，设置页「行为」分类可改为三种模式，并显示当前选择
- 退出必须真正结束进程（托盘菜单退出与关闭对话框退出一致）

## 关键取舍

- 命名管道按用户命名（含用户 SID 或用户名哈希），避免不同用户互相干扰
- 关闭对话框用项目现有模态组件，不引入 QMessageBox 原生样式
- 记住选择存 settings.obox.close_action，枚举值 ask/tray/quit，与设置页共用

## 与基线的冲突

- 基线没有托盘、单实例与关闭行为；需新增一节并在设置页加分类
- 关闭按钮当前直接退出，改为受配置控制

## 假设

- Windows 10+，托盘可用
- 设置项沿用 contributes/内置设置结构
