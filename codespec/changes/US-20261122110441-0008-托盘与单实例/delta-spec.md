# 托盘与单实例 Delta Spec

## ADDED Requirements

### Requirement: 单实例运行

obox SHALL 保证每个 Windows 用户最多一个运行实例：启动时以按用户命名的本地管道探测，已有实例则发送显示请求并退出，没有则成为主实例并监听管道。

#### Scenario: 第二次启动
- **WHEN** obox 已在运行，用户再次启动
- **THEN** 新进程退出，已运行实例的窗口显示并置前

#### Scenario: 不同用户互不干扰
- **WHEN** 两个 Windows 用户各自启动 obox
- **THEN** 各有一个实例，管道名不同，互不唤醒

### Requirement: 托盘常驻

obox SHALL 在系统托盘显示图标：双击恢复主窗口，右键菜单提供显示主窗口、打开设置、退出；托盘对象在最小化到托盘后仍存在，退出时移除。

#### Scenario: 托盘恢复
- **WHEN** 窗口已最小化到托盘，用户双击托盘图标
- **THEN** 主窗口恢复显示并置前

#### Scenario: 托盘退出
- **WHEN** 用户点击托盘菜单的退出
- **THEN** 进程结束，托盘图标消失

### Requirement: 关闭行为

关闭主窗口时 SHALL 按配置处理：询问时弹出三选一（最小化到托盘、退出、取消）并可勾选「记住我的选择」；直接最小化时不询问；直接退出时不询问。选择「记住」后写入配置并更新设置页显示。

#### Scenario: 首次关闭询问
- **WHEN** 关闭行为为询问，用户点关闭
- **THEN** 出现三选一对话框，取消则窗口保持

#### Scenario: 记住选择
- **WHEN** 在对话框中勾选记住并选择最小化
- **THEN** 配置写入 close_action=tray，下次关闭不再询问，直接最小化

### Requirement: 关闭行为设置

设置页 SHALL 新增「行为」分类，提供关闭行为选项（每次询问 / 最小化到托盘 / 直接退出），修改即时生效并持久化到配置。

#### Scenario: 设置切换
- **WHEN** 在设置里把关闭行为改为直接退出
- **THEN** 关闭窗口直接退出，配置为 quit
