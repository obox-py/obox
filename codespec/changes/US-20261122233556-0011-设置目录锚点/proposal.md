# 视图锚点 · 通用滚动与吸顶能力

## 背景

设置页一度改成单页章节 + 吸顶目录，实际使用后反馈偏紧凑，要求还原原布局。锚点能力本身仍有价值：任何扩展的视图都可能需要「点目录滚到章节、滚动时高亮」，因此本次保留通用锚点与 sticky 吸顶能力，设置页回到改版前的「左侧分类切换 + 右侧条目」。

## 目标

- 视图内任意元素的 id 可作为锚点，扩展可要求平滑滚动到它（约 600ms，顶部偏移可配，缺省 64）
- 滚动时按视口位置算出当前锚点并回推给扩展，用于目录高亮
- 视图根的直接子组件可声明 sticky，成为吸顶条
- 设置页保持原布局，不受本次能力影响

## 范围

**做：**

- 新增滚动消息与当前锚点事件两条消息
- 新增滚动控制器：目标值计算、平滑动画、锚点归属（含到顶到底）
- 视图装配识别 sticky 并把该组件抬到滚动区上方
- 单元测试与扩展开发文档

**不做：**

- 不改设置页布局与交互（已还原）
- 不做嵌套锚点、二级目录、折叠章节
- 不引入第三方滚动库；组件标签数不变

## 需求草案

1. 扩展发送滚动消息（视图 id、锚点 id、偏移、时长），obox 平滑滚到目标组件
2. 缺省时长 600ms、偏移 64px；目标值夹在滚动范围内
3. 滚动时按「视口顶部 + 偏移」算当前锚点，变化时向扩展投递事件
4. 到顶为第一章节、到底为最后章节；无章节时不投递
5. 视图根的直接子组件写 sticky="true" 成为吸顶条，固定在滚动内容之上

## 关键取舍

- 锚点只认视图根的直接子组件：章节是页面的一级块，不做任意深度查找
- sticky 在装配时抬出滚动区，而不是在滚动区内做悬浮覆盖：实现简单、不挡内容
- 平滑滚动用 QPropertyAnimation 驱动滚动条，不引入动画框架
- 高亮以「视口顶部 + 偏移」取最后一个越过的章节，不监听每个章节的可见性
- 设置页改版撤回：单页堆叠在内容不多时反而更紧凑，回到左分类右条目的原结构

## 与基线的冲突

- 基线「视图文件格式」没有 sticky 与锚点语义，需 ADDED 一条
- 基线「设置扩展」保持原描述，不改
- 「注册点」「主界面三段布局」不受影响

## 假设

- 偏移与时长由消息参数决定，缺省 64 / 600（已确认）
- 吸顶条由扩展自己渲染内容，obox 只负责抬出与定位
