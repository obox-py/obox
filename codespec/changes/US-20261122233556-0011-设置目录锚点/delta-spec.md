# 视图锚点 Spec Delta

## Purpose

给扩展视图补一条通用的「滚动到锚点 + 当前锚点回推」能力，并允许视图把一个直接子组件声明为吸顶条；设置页维持原布局。

## ADDED Requirements

### Requirement: 视图锚点与滚动

obox SHALL 支持视图内的锚点跳转：扩展发一条滚动消息，带视图 id、锚点 id（即目标组件 id）、顶部偏移与时长，obox 在该视图的滚动区里平滑滚到目标组件位置，时长缺省 600 毫秒、偏移缺省 64 像素，目标值夹在滚动条范围内。滚动过程中 obox SHALL 以「视口顶部加偏移」为基准计算当前所在锚点，变化时向该视图的扩展投递当前锚点事件；滚到最顶时当前锚点为第一个章节，滚到底时为其后最近的章节；过滤后一个章节都不存在时不投递事件。视图根的直接子组件带 sticky 属性时，obox SHALL 把它从滚动内容里抬出，固定在滚动区上方。

#### Scenario: 点击目录跳到章节

- **WHEN** 扩展发滚动消息要求跳到锚点 section-b，偏移 64
- **THEN** 视图在约 600 毫秒内平滑滚到该章节，章节顶部距视口顶部 64 像素

#### Scenario: 滚动高亮

- **WHEN** 用户手动把视图滚过某个章节
- **THEN** obox 投递当前锚点事件，扩展据此高亮目录项

#### Scenario: 到顶与到底

- **WHEN** 滚动到最顶或最底
- **THEN** 当前锚点分别为第一个章节与最后一个章节，不会出现空值

#### Scenario: 吸顶组件被抬出滚动区

- **WHEN** 视图根的第一个子组件声明 sticky="true"
- **THEN** 该组件固定在视口顶部，其余组件在它下方滚动

## MODIFIED Requirements

### Requirement: 视图文件格式

改自基线「视图文件格式」：补 sticky 与锚点语义。

扩展 SHALL 通过 .oml 文件路径注册视图；片段里的组件 id 同时是锚点标识；视图根的直接子组件可以声明 sticky（true）成为吸顶条，obox 把它固定在滚动区上方；sticky 组件不参与滚动内容的高度计算。

#### Scenario: 锚点 id 即组件 id

- **WHEN** 扩展把章节容器 id 写成 section-about，并请求滚动到该锚点
- **THEN** obox 找到该组件并滚到它的位置

## Impact

- 新增两条消息，扩展可用；obox 增一个滚动控制器
- sticky 影响视图装配：视图根的直接子组件会被移出滚动内容
- 设置页布局不变，原截图与场景继续有效
- 组件标签数量不变
